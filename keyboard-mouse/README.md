# Keyboard and mouse (moved)

Keyboard and mouse is built into OpenRAC now. Ratchet & Clank (PAL and
NTSC-U) plays with a keyboard and mouse out of the box: nothing to install,
always on. The game starts on the gamepad and switches to the keyboard and
mouse the moment you use them.

Its binds, presets and settings are on the launcher's **Mods** tab, under
**Built in**. Docs and code:
[docs/port/KEYBOARD_MOUSE.md](https://github.com/OpenRAC/OpenRAC/blob/develop/docs/port/KEYBOARD_MOUSE.md)
and `port/game/rac1/keyboard_mouse/` in the OpenRAC repository.

An installed copy of this mod is not loaded any more and the launcher no
longer lists it. Set your binds again on the built-in entry.
